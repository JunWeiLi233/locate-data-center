# Frontend scope

The user's 2026-10-03 frontend request explicitly authorizes this separate application and supersedes the older project description's “No frontend” statement for this directory. All scientific, provenance, unknown-data and geographic interpretation rules still apply.

Do not modify `src/dc_locator`, baseline `configs`, accepted phase records or existing run outputs. The server is a transport/presentation adapter to the existing model. New model request configurations and outputs belong under `runs/frontend_service/`. Synthetic browser fixtures belong under `src/mocks/` and must be labeled DEMO DATA throughout the interface.

Keep API schema versioned, geometry in longitude/latitude EPSG:4326, all missing values null, and metrics' units/status/source explicit. Never infer utility capacity, fiber, zoning, community support or confirmed heat partners. Never compute MCDA, favorable risk normalization or AHP final weights in the browser.
