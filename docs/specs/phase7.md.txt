You are implementing PHASE 7, the integration and delivery phase,
of dc_locator.

Read AGENTS.md and all previous handoffs.
Inspect the repository and actual outputs.

GOAL

Make the existing system executable end to end without manual
notebook editing.

Do not expand the project into a frontend or AI-agent platform.

PRIMARY WORKFLOW

A user supplies facility requirements and configuration.

The application:

loads/builds the U.S. grid
→ loads acquired source data
→ constructs geographic features
→ evaluates constraints
→ calculates facility impacts
→ applies decision preferences
→ identifies candidate regions
→ runs requested robustness checks
→ exports results and limitations.

CLI

Provide documented commands for:

build-grid

run

An example top-level command should resemble:

python -m dc_locator run \
    --config configs/run.yaml \
    --output runs/example

Implement the actual entry point rather than only documenting it.
