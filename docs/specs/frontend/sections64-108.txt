67. SEARCH CANCELLATION / STALE RESULTS
==================================================

Users may change parameters while a previous request is running.

Prevent stale results.

Use AbortController or the framework's equivalent.

Example:

Search A starts.

User changes:

100 MW
→
200 MW

and starts Search B.

Cancel Search A if possible.

If Search A later returns anyway, do NOT overwrite Search B.

Track the active request/run identifier.
