110. MODEL CONFIGURATION VS MAP FILTERS
==================================================

Clearly separate:

MODEL CONFIGURATION

from:

MAP DISPLAY FILTERS.

MODEL CONFIGURATION changes the calculation.

Examples:

100 MW → 200 MW
cooling design
water constraint
AHP weights
future scenario
minimum land requirement

These require backend recalculation.

MAP DISPLAY FILTERS only change visualization.

Examples:

show top 10
show Pareto only
hide conditional candidates
toggle water layer
toggle infrastructure

These should not rerun the model.

Make this distinction clear in code and UI.
