# Sustainable data-center locator implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement this plan phase by phase. The orchestrator reviews requirements and code, runs verification, records acceptance, and only then dispatches the next phase.

**Goal:** Deliver a deterministic, reproducible CONUS grid-to-candidate-region application with honest source coverage and UNKNOWN handling.

**Architecture:** Preserve the existing package, grid definition, IO metadata, and provenance vocabulary. Geography adapters produce an independent grid dataset; screening, physical calculations, decision analysis, scenarios, and validation consume it. The CLI orchestrates these components without inventing unavailable evidence.

**Tech stack:** Existing Python 3.12 virtual environment, GeoPandas/Shapely/PyProj, Rasterio, Pandas/Arrow, NumPy/SciPy, Pydantic/YAML, pytest.

## Execution contracts

- Work in the existing project directory; it already contains useful uncommitted implementation and cached data. Preserve that work. No remote publication is part of this request.
- One primary implementation agent per phase, sequential phase gates. Focused independent reviews may run alongside orchestrator verification.
- Production logic belongs in `src/dc_locator/`; synthetic fixtures belong in `tests/fixtures/` or explicitly synthetic run folders. Never synthesize missing real features.
- Use the exact existing grid IDs and table IO helpers. Record any schema migration in `docs/data_contracts.md`.
- Every important feature and calculated metric retains value, units, source, period, spatial resolution, method, status, confidence and missing reason.
- Acquired/implemented/analyzed are separate coverage concepts. National geometry does not imply national feature or model completion.
- Record actual source checksums and code revision plus working-tree fingerprint because the initial implementation is uncommitted.

## Delivery interpretation

The result identifies regions deserving further investigation under the recorded inputs, assumptions and preferences. No output establishes parcel buildability or an objectively best national site. Source access and incomplete coverage remain explicitly reported limitations.
